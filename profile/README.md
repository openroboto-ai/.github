# OpenRoboto

**Robot intelligence built in the open.**

OpenRoboto is an open competition on [Bittensor](https://bittensor.com) for continuously improving robotics models. Miners pull the current base model (π0.5 via [openpi](https://github.com/Physical-Intelligence/openpi)), fine-tune it, and submit the weights on-chain. The network scores every challenger on a shared benchmark under the same conditions. A model only replaces the base if it scores better — the winning miner takes the emission, and the improved model becomes the next base.
